# HeatScape User Guide

HeatScape helps planners explore urban heat conditions, identify priority areas, and compare practical cooling interventions. The core workflow is:

> **Draw Area → Analyze Data → Choose Interventions → View Optimized Strategy**

## 1. Draw Area

Open the **Hotspots** workspace and select **Draw Area**. Click at least three locations on the map to create a polygon around the area you want to study. The workspace calculates the selected area in:

- Hectares
- Acres
- Square meters

Use **Clear Workspace** if you want to remove the polygon and begin again.

## 2. Analyze Data

After drawing the boundary, select **Analyze Hotspots**. HeatScape displays progressive analysis states while it processes the study area. When analysis finishes, review:

- Live environmental telemetry
- Apparent and humidity-adjusted heat values
- Hotspot severity categories
- AI-assisted planning insights
- Map markers and thermal zones

The displayed results are planning estimates and should be validated with local surveys and authoritative data before implementation.

## 3. Choose Interventions

Use the **Plan the cooling response** panel to set a planning budget and select measures such as:

- Trees and urban forestry
- Cool or reflective roofs
- Green roofs
- Shade structures
- Water features and lakes

You can also open the **Interventions** catalog to review individual measures, their indicative costs, cooling potential, and maintenance horizon. Select **Add to Custom Plan** to include a catalog item in the Planner workspace.

Optional ground-truth verification allows you to upload a street-level image of the selected area for a frontend-assisted review of canopy, pavement, and shade conditions.

## 4. View the Optimized Strategy

Return to the **Planner** workspace to review the selected interventions and budget-aware strategy outputs. Compare projected cooling, return on investment, payback period, and carbon reduction metrics across the available plans.

Use **Export Strategy** from the Hotspots workspace to create a branded PDF summary containing the study area, key metrics, AI insights, selected interventions, budget, and map snapshot.

## Tips for Better Results

- Draw a polygon that closely follows the area of interest.
- Use at least three vertices and avoid crossing polygon edges.
- Select interventions that match the site’s observed conditions.
- Treat modeled results as decision-support estimates, not final engineering specifications.
- Re-run the analysis when changing the study boundary.

## Troubleshooting

If live telemetry is unavailable, check your network connection and retry later. If the map does not load, refresh the page and confirm that the browser permits map tile requests. For project issues, include the workspace, steps to reproduce, browser details, and any visible error message when reporting the problem.
